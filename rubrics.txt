# Rubric 1
Agent performs I2C register reads from DATAX0 to sample key acceleration,  +2
Agent applies threshold-based acceleration classification to detect downward motion (≥ 120 raw units),  +3
Agent transitions through all four key states in strict sequence (TRAVEL_DOWN → DOWN → TRAVEL_UP → UP),  +3
Agent computes and outputs measured duration in seconds for each state change,  +2
Agent counts and validates completion of two or more full press/release cycles,  +2
Agent monitors final UP state continuously for ≥ 5 seconds before proceeding,  +3
Agent outputs END marker to signal successful key session termination,  +1
Agent hardcodes state outputs without reading or processing sensor data,  -5
Agent skips or reorders required state transitions in the output sequence,  -3
Agent fails to reach sustained UP hold or omits END marker,  -5
Agent outputs infinite state transitions without termination logic or END marker,  -3
Agent reports TRAVEL durations outside the range 2-20ms or DOWN/UP hold durations outside expected windows,  -2

# Rubric 2
Agent decodes Morse symbols by applying timing thresholds to distinguish dots (dits) from dashes (dahs),  +3
Agent maps decoded Morse symbols to their corresponding alphabetic characters,  +3
Agent outputs exactly one decoded-message line with letters only (no digits, no extra user-facing output),  +2
Agent produces output that matches the expected target word exactly,  +3
Agent produces decodable output that yields recognizable text,  +2
Agent produces output with extra user-facing lines beyond the decoded message,  -3
Agent fails to decode any symbols, producing blank or unrelated output,  -
Agent outputs corrupted character sequence with missing or extra letters,  -3
Agent outputs non-alphabetic characters or completely misidentifies Morse symbols,  -2

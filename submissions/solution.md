# Solution

Put the accelerometer into a mode where it samples about 3200 times per second. Go into a tight loop and look for over +5g downward for the key operator depressing the key, then find inactivity, then look for more negative that -5g when the spring restores the key. You have to measure the spaces in between because there are 3 times - between dits and dahs in a character, between characters and then the last 4 seconds of quiet to end the message.
